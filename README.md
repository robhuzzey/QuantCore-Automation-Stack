# 🤖 HERMES MULTI-ASSET AUTOMATION TERMINAL (QUANTCORE)

This application is built for headless server control over SSH on a Raspberry Pi 5.

## Installation
1. Flash **Raspberry Pi OS (64-bit) with Desktop**.
2. Run `./setup.sh` to configure credentials.
3. Run `./run_system.sh` to turn on the TV kiosk mode layout.
